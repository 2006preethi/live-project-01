# Bangalore Tech Salary Decoder

This project analyzes a dataset of Bangalore tech professionals using Python, Pandas, and NumPy.

## Features
- Data loading and inspection
- Data cleaning and preprocessing
- Salary analysis by role
- Experience-based salary analysis
- Skill premium analysis
- Company type salary comparison
- Underpaid employee identification
- Final business insights

## Tools Used
- Python
- Pandas
- NumPy
- Google Colab

Created as part of **The Unlox Academy Live Project**.
